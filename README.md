# ROUTE MATE — 차량 생활동선 도우미

> 차량이 서 있는 위치와 이동 경로, 사용자가 정한 **돌아올 시각**을 함께 고려해 안전한 주차와 생활정보를 안내하고,
> 원할 때만 주변의 짧은 일감을 골라 연결해 주는 차량용 앱입니다. (현대자동차그룹 차량용 앱 개발 공모전 출품작 시제품)

추천의 기준은 주차장 목록이나 구인 목록이 아니라 **정차 한 번(위치 × 머무는 시간 × 돌아올 시각)** 입니다.
쉬기·볼일 보기·짧게 일하기는 모두 같은 무게의 선택지이며, 일을 권하거나 강요하지 않습니다.

> 🚗 **바로 써 보기: https://route-mate-eboj.onrender.com** (로그인 없음, PC 가로 화면 권장 · 무료 서버라 한동안 접속이 없으면 첫 화면까지 50초쯤 걸릴 수 있어요)
> 화면 아래 **시연 도구 → ▶ 실시간 자동 진행**을 누르면 사고·비·새 일감·찾던 물건 매물이 시간표대로 일어나고, 도우미가 먼저 말을 겁니다.

> ⚠️ **주차장·일감·상점 정보는 모두 시연용 가상 데이터입니다.** 아직 제휴가 없는 시제품이라 실제 매장·보수·요금이 아니며, 화면에도 `[샘플]`로 표시합니다.

## 이번 제출에서 실제로 동작하는 기능

기획서의 기능 이름(영문)은 괄호 안에 함께 적었습니다.

| 기능 | 구현 위치 | 상태 |
|---|---|---|
| ① **주차장 비교** (PARKING TRUTH) — 공식 요금표로 머무는 시간 동안의 총요금 계산, 운영 시간·높이 제한 확인, 할인 반영, 출처·갱신 시각·미확인 표시 | `backend/app/engine/parking.py` | ✅ |
| ② **안전 승하차** (SAFE PICKUP) — 합법적으로 타고 내릴 수 있는 곳만 보기, 목적지까지 걷는 시간 | 같은 파일 (`pickup_only`) | ✅ |
| ③ **여유 시간 설정** (FLEX WINDOW) — 돌아올 시각·복귀 지점·최소 여유·운전 시간 상한·원하는 업무 설정, 일감 끄기(쉬기) | `engine/flex_window.py`, `POST /api/sessions` | ✅ |
| ④ **동선 맞춤 일감** (ROUTE-FIT MATCH) — (A) 법률 검토·자격·보험·정차 공간 필수 확인 → (B) 이동·업무·복귀·안전 여유 합산 → (C) 돌아올 시각을 넘기면 제외 → (D) 운전 시간·순수익·업체 신뢰도로 정렬. 예상 순수익과 시간당 순수익 표시 | `engine/flex_window.py` | ✅ |
| ⑤ **차량 특화** — 주행 중 상세 보기·수락 차단(서버에서도 423으로 거부), 짧은 음성 안내, 수락 시 업무지 → 복귀 지점 경로 안내 | `engine/safety.py`, `frontend/` | ✅ (시뮬레이터) |
| ⑥ **주변 생활정보** (ROUTE RADAR) — 미리 고른 항목만 근처 정보와 연결, 광고·제휴는 따로 표시 | `engine/radar.py` | ✅ |
| 음성 요청 해석 ("17:55까지 이곳에 돌아와야 해요…") | `engine/intent.py` | ✅ 규칙 기반 (LLM으로 교체 가능하게 분리) |
| 한 일감은 한 명만 수락 · 같은 요청 중복 처리 방지(`Idempotency-Key`) · 업무 상태 관리 · 이용 기록 | `backend/app/store.py` | ✅ (8명이 동시에 수락해도 1명만 성공) |
| 거절한 일감은 다시 추천하지 않음 (거절해도 불이익 없음) | `POST /api/sessions/{id}/decline` | ✅ |
| 교통 정체·업무 취소·주차장 만차 → 새 추천 중지, 복귀·지연 안내·다른 합법 주차장 안내 | `POST /api/sessions/{id}/events` | ✅ |
| 위치 정보 동의 필수, 동의 철회 시 기록 삭제, 이용 기록의 위치는 약 100m 단위로만 저장 | `store.py` | ✅ |
| **실시간 상황 판단 · 먼저 말 걸기** — 사고·정체·비·학원 하원 정체·학원/병원 일정 변경·새 일감을 지켜보다가, 내 동선이나 약속 시각에 영향이 있을 때만 먼저 말을 겁니다. 늦을 위험이 있으면 "업체에 늦는다고 알리기 / 일 취소하고 돌아가기"를 함께 제시 | `engine/situation.py`, `GET /api/sessions/{id}/situation` | ✅ (시연용 상황 시간표) |
| 실시간 교통 상황을 일감 추천·복귀 시각 계산에 반영 (사고가 나면 그 길을 지나는 일은 자동으로 빠짐) | `engine/flex_window.py` | ✅ |
| **주차가 안 될 때 대안** — 학원 앞이 막히거나 주차장이 꽉 차면 "한 바퀴 돌고 오시는 게 좋겠어요"와 함께 주차 되는 카페·마트(예: 음료 사면 1시간 무료)를 제안 | `GET /api/waiting-spots`, `engine/situation.py` | ✅ |
| **찾던 물건 알림 (동네 중고거래 연동 가정)** — 평소 찾는 물건(예: 유아 카시트)을 등록해 두면, 근처에 올라오고 돌아올 시각 전에 다녀올 수 있을 때만 "찾으시던 유아 카시트가 근처에 올라왔어요. 4만 원이고, 거의 새것이래요…"라고 읽어 주고, 수락하면 판매자에게 구매 메시지를 보내고(시연: 실제 발송 없음) 그 동네로 길 안내 | `POST /api/sessions/{id}/market/{매물}/go` | ✅ (가상 매물) |
| **불법 주정차 손해 안내** — 목적지 앞이 단속 구간이면 과태료와 주차장 요금을 나란히 보여 주고, 오늘 이 구역 예상 단속액을 실시간 카운터로 표시해 합법 주차를 권함 | `GET /api/enforcement` | ✅ (시연용 추정치) |

### 아직 구현하지 않은 것

기획서의 "실제 구현 성과를 허위로 기재하지 않는다"는 원칙에 따라 그대로 적습니다.

- **Pleos Connect 차량용 앱(APK)** — 개발 PC에 Android 개발 도구가 없어 이번에는 빌드하지 못했습니다. 대신 차량 중앙 화면과 같은 흐름을 **웹 시뮬레이터**(`frontend/`)로 만들었고, 서버 API는 차량용 앱이 그대로 호출할 수 있게 설계했습니다.
- **Pleos SDK 연동** (위치·차량 상태·내비게이션·음성) — 지금은 `engine/geo.py`의 보수적인 거리·시간 추정과 브라우저 음성 안내로 대신합니다. 실제 API·권한·에뮬레이터 지원 범위를 Pleos 공식 문서로 확인한 뒤 교체할 예정입니다.
- **PostgreSQL** — 지금은 메모리 저장소와 잠금으로 처리합니다. 같은 규칙을 `SELECT … FOR UPDATE`와 중복 방지 키 고유 제약으로 옮길 예정입니다.
- **실제 데이터** — 공공 주차시설 데이터와 제휴 운영사·매장 정보는 아직 연결하지 않았습니다. 빈자리·발레파킹·실시간 요금은 확인할 수 있는 출처가 없으면 "미확인"으로 표시하는 동작까지만 구현했습니다.
- **LLM** — 음성 요청 해석 부분만 LLM으로 바꿀 수 있게 나눠 두었고, 안전·계약 판단은 언제나 규칙 기반 코드가 합니다.
- 실제 서비스 전에는 **유상운송 보험, 근로·중개 관련 법률 검토**가 반드시 필요합니다.

## 도우미가 먼저 말을 거는 원칙

대상은 아이 픽업·병원 동행 같은 돌봄 일정 사이사이에 짧게 일하는 사람(전업주부·긱워커 등)입니다. 운전 중이거나 아이를 기다리는 사람에게 말이 많으면 방해가 되므로 아래 원칙을 지킵니다.

1. **결정이 바뀔 때만 말합니다.** 사고가 나도 내 동선과 관계없으면 조용히 있고, 화면의 '지금 주변 상황'에만 표시합니다.
2. **돌봄 약속이 일보다 먼저입니다.** 늦을 위험이 생기면 "아이 픽업이 먼저니까, 업체에 늦는다고 말해 두고 바로 출발하세요"처럼 일을 접는 쪽을 권합니다.
3. **한 번 한 말은 반복하지 않습니다.** 상황이 더 나빠졌을 때만(예: 사고 → 사고+비) 다시 말합니다. 같은 순간에 여러 말을 겹쳐 하지 않습니다.
4. **주행 중에는 짧게, 정차 중에는 선택지와 함께** 말합니다.
5. **쉬기로 한 사람에게 일을 권하지 않습니다.** 대신 "비가 와요, 우산 챙기세요" 같은 생활 안내만 합니다.

### 음성 대본 원칙

- 결론부터, 한두 문장으로 말합니다. ("35분 있어요. 시간 맞는 일이 두 개 있는데, 그냥 쉬셔도 돼요.")
- "안내할게요", "확인해 주세요" 같은 기계적인 말투 대신, 사람이 옆에서 말하듯 씁니다. ("꽃집 일 잡았어요. 5시 25분쯤 도착하고, 5시 48분이면 여기로 돌아와요.")
- 시각은 "오후 5시 55분"처럼 읽고, 숫자 뒤 조사는 읽었을 때 자연스러운 형태("~분이면", "~까지로")를 씁니다.

### 단속 정보에 대한 원칙

목적지 앞이 단속 구간이라는 사실과 과태료, 오늘 예상 단속액은 **합법 주차를 권하기 위해서만** 보여 줍니다. 단속 시간대나 카메라 위치처럼 단속을 피하는 데 쓰일 수 있는 정보는 내보내지 않습니다(테스트로 확인). 단속액은 지자체 공개 통계 연동 전까지 시연용 추정치로 표시합니다.

## 대표 시연 장면 (가상)

17:20, 보호자가 18:00에 끝나는 자녀의 학원 수업을 기다리며 도착합니다.

1. **주차** — 목적지 근처 주차장을 비교합니다. 18:00에 문을 닫는 C와 높이 제한 1.85m인 D는 *이유와 함께* 제외합니다. 확인되지 않은 할인은 요금에 반영하지 않고 "확인 필요"로 따로 보여 줍니다.
2. **여유 시간 설정** — "주차 후 17:55까지 이곳에 돌아와야 해요. 시간이 남으면 가까운 일도 볼래요"라고 말하면 해석 결과를 화면에 채워 주고, 사용자가 확인한 뒤 시작합니다.
3. **추천** — `[샘플] 꽃집 꽃다발을 받아 근처에 전달`: 이동 5분 + 업무 10분 + 복귀 5분 + 안전 여유 8분 = 28분 → 17:48 복귀(약속보다 7분 일찍), 예상 순수익 11,600원. 보험이 없거나, 시간을 넘기거나, 검증되지 않은 업체의 일감은 이유와 함께 제외합니다. "잠시 쉬기"는 언제나 같은 무게의 선택지입니다.
4. **수락** — 차가 서 있을 때(P단)만 가능합니다. 업무지를 거쳐 복귀 지점까지 안내하고, 교통 정체·업무 취소·만차가 생기면 새 추천을 멈추고 복귀를 먼저 안내합니다.
5. **복귀 후 픽업** — 이용이 끝나면 위치 정보와 이용 기록을 삭제할 수 있습니다.

## 실행 방법

필요 환경: Python 3.11 이상

```bash
pip install -r requirements.txt
```

```bash
python -m uvicorn app.main:app --app-dir backend --port 8765
```

브라우저에서 <http://localhost:8765>를 열면 차량 화면 시뮬레이터가 나옵니다. 화면 아래 **시연 도구**(실제 차량 화면에는 없는 영역)에서 시각 넘기기, 주행·정차 전환, 교통 정체·업무 취소·만차 상황을 만들어 볼 수 있습니다. API 문서는 <http://localhost:8765/docs>에서 볼 수 있습니다.

### 음성 안내

- 브라우저가 제공하는 한국어 목소리 중 **가장 자연스러운 신경망 음성을 자동으로 고릅니다** (예: Microsoft Edge의 SunHi·InJoon, Chrome의 Google 한국어 음성). 설정(⚙)에서 목소리·말하기 속도를 바꾸거나 음성 안내를 끌 수 있습니다.
- 화면 문구를 그대로 읽지 않고 **말하기용 문구로 바꿔 읽습니다.** 예: `17:55` → "오후 5시 55분", 기호·괄호 제거, 문장 단위로 끊어 읽기, 안내 전 짧은 알림음.
- Windows 기본 음성(Heami)만 있는 환경에서는 기계음에 가깝게 들립니다. 시연 영상은 **Microsoft Edge로 열어 녹화하는 것을 권장**합니다.
- 실제 차량에서는 Pleos의 음성 합성(TTS) SDK로 교체합니다. `frontend/voice.js`의 `speak()`만 바꾸면 됩니다.

### 테스트

외부 패키지 없이 표준 라이브러리 `unittest`로 실행합니다. (51개)

```bash
python -m unittest discover -s backend/tests -v
```

## 폴더 구조

```
backend/
  app/
    main.py              서버 API (차량용 앱이 호출)
    store.py             정차 기록 · 일감 수락 처리 · 중복 방지 · 업무 상태 · 이용 기록
    engine/
      parking.py         주차장 비교 · 안전 승하차
      flex_window.py     여유 시간 설정 · 동선 맞춤 일감 (A→B→C→D)
      radar.py           주변 생활정보
      intent.py          음성 요청 해석 (규칙 기반)
      safety.py          주행 중 조작 제한
      geo.py             거리·소요 시간 추정 (내비게이션·위치 SDK로 교체할 부분)
    data/                시연용 가상 데이터 (주차장·일감·생활정보)
  tests/                 계산 로직 단위 테스트 + API 시나리오 테스트
frontend/                차량 중앙 화면 웹 시뮬레이터 (HTML/CSS/JS, 빌드 불필요)
  app.js                 단계별 화면 (주차 → 시간 설정 → 선택 → 진행), 지도, 설정
  voice.js               음성 안내 (자연스러운 목소리 선택, 말하기용 문구 변환)
```

### 주요 API

| 방식 | 경로 | 설명 |
|---|---|---|
| POST | `/api/parking/search` | 주차장 비교 (예상 요금·걷는 시간·출처·미확인 상태, 제외 이유) |
| POST | `/api/intent` | 음성 요청 → 여유 시간 설정값 제안 |
| POST | `/api/sessions` | 여유 시간 계획 시작 (위치 정보 동의 필수) |

## 안전·품질 원칙

- 주정차 단속을 피하는 정보나 불법 정차 장소는 데이터에 두지 않으며, 추천하지 않습니다.
- 주행 중에는 긴 입력·상세 보기·수락을 막습니다. (서버에서도 막습니다)
- 보험이 없거나, 검증되지 않았거나, 법률 검토가 끝나지 않은 일감은 점수와 상관없이 추천하지 않습니다.
- 자녀 신상이나 학원 정보는 받지 않습니다. 목적지는 사용자가 지정한 좌표만 사용합니다.
- 확인할 수 없는 정보는 숨기거나 짐작하지 않고 "미확인"으로 표시합니다.

## 단계별 계획

- **1단계 (이번 시제품)** 주차장 비교·예상 요금 · 여유 시간 설정 · 복귀 시각 기준 필터 · 경로 안내 데이터
- **2단계** Pleos 차량용 앱 · 내비게이션·차량 상태 SDK 연동 · 승인된 일감 연결 · PostgreSQL
- **3단계** 안전 승하차 고도화 · 지역 가게 참여 · 학원가 1개 생활권 시범 운영
